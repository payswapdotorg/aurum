# Aurum Domain Mapping

Foundation: tenants, organizations, identity, people, world, events, observations, evidence, freshness, audit.
Intelligence: memory, epistemics, goals, attention, unknowns, learning, learning-missions, knowledge-acquisition, cognition, environment, opportunities.
Operating model: processes, capabilities, automation, workforce, suppliers, outcomes.
Agent economy: agents, agent-teams, agent-packages, extensions, marketplace, recruitment, ExecutionPlans, information-relay.
Interaction: conversations, channels, notifications, briefings, api, mcp.
Provider/execution control: provider-definitions, provider-accounts, provider-protocols, model-catalog, model-bindings, provider-health, provider-availability, secrets, execution-environments.

Observation = evidence encountered.
Claim = evidence-derived proposition.
Belief = versioned current understanding.
Hypothesis = unresolved explanation.
Unknown = consequential question plus consequence.
Contradiction = retained conflict.
Freshness = temporal validity.

Goals contain objective, desired state, metrics/thresholds, horizon, owner, priority, expected evidence, success criteria and history.
Learning missions contain knowledge objective, affected goals/decisions, unknowns, urgency, confidence, information value, budget, candidate sources/people/systems, optional agent commission, evidence and outcome.
Capabilities are supplied by employee/team/agent/software/supplier/partner; requirements arise from goal/process/project/opportunity/manual; gaps distinguish uncovered/level/capacity shortfalls.
Processes expose bottlenecks, duplication, handoffs, manual effort, errors, variants and waiting time.
Workforce includes roles, capabilities, assignments, capacity, workload, outcomes, alternative explanations, training, reassignment, hiring, agent complement/replacement, automation and outsourcing.

OrganizationCandidate contains mixed human/agent/software/external actors, assignments, capability/workload allocation, execution/information topology, delegation, review, escalation, handoffs, model occupancy, environment, budget, expected outcome, risk and evidence.

Context may include season, date/window, duration, staffing, experience, workload, geography, budget, SLA, quality, inspection intensity, risk tolerance, environment capability and evidence freshness.
